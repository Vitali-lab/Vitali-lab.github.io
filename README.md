# vitfolio

Персональный сайт-визитка фронтенд-разработчика: React + TypeScript + Vite,
без UI-библиотек. Визуальная система собрана по мотивам
[kalcheuski.com](https://kalcheuski.com/?lang=pl): светлая бумага, один ink,
Inter + IBM Plex Mono, крупная типографика, тонкие рамки. От референса осталась
интонация, но не предметы: висящий бейдж убран, хедер один и всегда на месте,
а вместо бейджа — контактная печать и бот-гид.

## Запуск

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run dev` поднимает Vite (если 5173 занят — берёт следующий порт).

## Публикация

Сайт собирается в `dist` и публикуется на GitHub Pages из репозитория
`Vitali-lab/Vitali-lab.github.io` через GitHub Actions (`.github/workflows/deploy.yml`).
Адрес — `https://vitali-lab.github.io/`.

в копирайте футера, чтобы не мешать работодателю.

## Первый экран

Hero занимает весь вьюпорт (`100svh`), а за текстом едут рядами плитки с
настоящими логотипами: JS, TS, React, Next, Redux, Vite, HTML5, Sass, Node,
Express, PostgreSQL, MongoDB, Firebase, Python, .NET, Docker, npm, Webpack,
Tailwind, Git, GitHub, Figma, Vercel, Netlify, OpenCode, Cursor, Claude,
DeepSeek, Telegram, Google. GPT, 1C и C# — текстовые плитки.

- Логотипы лежат в `public/logos/` (Simple Icons, SVG). Плитки 64px, шаг 9px,
  логотип 26px с прозрачностью 26%. Ряды едут в разные стороны (68–114 с), при
  `prefers-reduced-motion` стоят. Количество плиток считается от окна: на
  1440×1000 — 15 рядов и 630 плиток, на телефоне — 306.
- Стена закрывает экран целиком, включая полосу под хедером; сверху ряда нет
  пустого пояса.
- На ховере плитка становится белой, а логотип — контрастным.
- В центре — радиальное «пятно» цвета бумаги, чтобы заголовок не спорил со
  стеной. Заголовок, подзаголовок и CTA стоят поверх.
- Над заголовком остаётся место под Бупа: он стартует там и со скроллом уходит
  вправо.
- На телефоне плитки 46px, завеса плотнее, а плавающий Буп скрыт — персонаж
  остаётся в логотипе хедера, чтобы не закрывать контент.

## Хедер

Один вариант, навсегда: фиксированная стеклянная пилюля сверху. Слева — лицо
персонажа, в центре — **Gooey Nav** из ReactBits, справа — Telegram. Никакой
второй версии, никакого hide-on-scroll, никакого «появился при скролле вверх».
На телефоне пилюля компактная, по содержимому и по центру: лицо и бургер из
трёх полосок; меню открывается полноэкранной шторкой, кнопка остаётся сверху.
Порядок пунктов совпадает с порядком блоков: Начало, О себе, Работы, Контакты.

Gooey Nav — единственный скопированный компонент: MIT + Commons Clause,
copyright David Haz. Он адаптирован по токенам (светлая тема, чернильная
активная пилюля, 4 пункта), а не переписан.

## Буп, гид

`Guide` — отдельный персонаж, а не просто шарик: у него есть имя, голос и
маршрут. Он живёт на фиксированном слое и стартует над зарезервированным
местом в hero.

- Пока страница не прокручена, он стоит на метке героя и следит за мышью.
- При малейшем скролле (4px) сразу делает лёгкое движение влево (10px),
  гаснет и уменьшается за 170ms; на экране его уже нет.
- Появляется у правого края за 300ms, задом наперёд: выезжает из смещения
  30px, чуть перелетает и садится. Через страницу он не едет.
- Скролл вверх запускает ту же пару наоборот: гаснет справа, появляется на
  месте в hero.
- Не комментирует блоки. Говорит, когда навели на карточку проекта (факт или
  шутка), когда открыли карточку проекта (одна из шести фраз) и изредка сам,
  пока сидит справа.
- При `prefers-reduced-motion` переключается между hero и доком без
  промежуточной анимации.

У Буп четыре выражения, и меняются в них только брови:

- обычное — ровные;
- любопытное — поднята одна правая бровь; включается на hover;
- доброе — обе приподняты и развёрнуты внутренними концами вверх; держится
  несколько секунд после тыка;
- злое — ближе к глазам и нахмурено внутренними концами вниз.

Глаза всегда на месте. Если открыть DevTools (докнутые, десктоп), тело и
пузырь краснеют, брови хмурятся, в пузыре появляется «Куда полез? Это не для
тебя.» Закрыли — снова белый и обычный.

Ещё два состояния:

- **сон**. Если 30 секунд нет ни движения, ни скролла, ни клавиш, глаза
  закрываются дугами, брови остаются прямыми над ними, а у плеча шара
  всплывают жирные `z z z` с белым ореолом. Любое движение будит.
- **речь**. При первом заходе он здоровается — 20 разных приветствий, выбор
  случайный. Пока сидит справа, раз в ~минуту выдаёт тихую реплику (8 штук).
  На ховере по проекту иногда шутит вместо факта.
- **уход**. Четыре быстрых тыка за 3 секунды — Буп краснеет, говорит колкость
  («Я не кнопка.» и в таком духе), улетает за правый край, пропадает на
  10 секунд и возвращается с какой-нибудь смешной фразой вроде «Ладно,
  прощаю.»

Справа он сидит как раньше: шар 72px, 24px от края, с мягкой тенью, чтобы
читался как часть страницы. Пузырь — как в мессенджере: чернильный,
скруглённый, с хвостиком из повёрнутого квадрата, который касается шара.
Ширина до 200px, текст печатается по буквам.

После «ухода» он возвращается не туда, где был, а туда, где страница сейчас:
позиция пересчитывается по текущему скроллу, поэтому кривого возврата нет.

Поле справа — 320px на 1440 и шире: карточки заканчиваются за 9px до пузыря,
поэтому реплика о проекте физически не ложится на карточки. На узких экранах
поле меньше (22vw), и пузырь может задеть край правой карточки.

На мобильном поле всего 16px, поэтому шар 52px стоит вплотную к краю
страницы — этого поля физически не хватает на больший отступ.

## Rows вместо веера

После героя — две ленты кейсов в духе slidshift: 16:9-карточки с нашими
CSS-обложками, два ряда едут в разные стороны, края растворяются маской,
на hover обе ленты встают. Под reduced motion — статичная полоса. Ленты
повторяют набор дважды для бесшовного цикла.

Ширина rows та же, что у работ: общий `.content-rail`, центрированный,
с полем `clamp(16px, 22vw, 320px)` с каждой стороны — правое поле и есть
полоса под Бупа.

## Работы

Десять 16:9-превью, как блок слайдов у slidshift: 3 колонки от 1360px, 2 ниже,
1 на телефоне; равные промежутки, никакой упаковки в masonry. Блок стоит по
центру страницы. Внутри — настоящий скриншот сайта, без рамки и полей: CRM,
БигФудМаркет, Golden Motors, приглашения, Holly, Автобус 1, Karma Studio,
этот сайт, PLENKA и Hush.

- Названия нет в покое: при наведении снизу поднимается стеклянная плашка с
  номером, названием и типом проекта; обложка чуть приближается, справа сверху
  появляется кружок со стрелкой. На тач-экранах название видно всегда.
- Наведение отдаёт Бупу строку о проекте: факт из `talk` или шутка из `joke`
  (40% случаев).
- Клик открывает карточку проекта, а не внешний сайт. У внутренней CRM ссылки
  нет — только описание, экраны и пометка, что система закрытая.
- Фильтры — чипы; скрытая карточка просто убирается, сетка пересобирается.

## Карточка проекта

`ProjectModal` — нативный `<dialog>` в top layer: Escape и фокус-трап дают
браузерные, фон становится inert. Ширина до 1120px, на телефоне — весь экран.

- Шапка — плоский ink без градиентов: номер, чип, название, описание и строка
  фактов (год, роль, стек).
- В шапке живёт Буп: он появляется с задержкой, моргает и говорит одну из шести
  фраз проекта (`enter` в данных). У каждого проекта свой набор.
- Дальше — карусель: один большой кадр, стрелки, счётчик, миниатюры, стрелки
  клавиатуры и свайп. Скриншоты — настоящие, сняты с живых сайтов. У «Автобус 1»
  их 16: все 12 сайтов холдинга плюс мобильные кадры и автопарк.
- Ниже — текст, блок «Что делал», ссылки на сайты и футер с Telegram.
- Скролл внутри листа работает, но полоса прокрутки скрыта.
- PLENKA и Hush используют реальные скриншоты и как обложку карточки.

## О себе и как я работаю

Оба блока стоят на той же колонке `.content-rail`, что rows и работы, — больше
не уже остальных.

- «О себе»: метка, крупное утверждение (28–40px), вторичный абзац и один
  широкий бумажный слэб: четыре группы стека в ряд, линия, три колонки фактов.
- «Как я работаю»: метка, лид на 760px и чёрный слэб с четырьмя строками
  (номер / название / текст), разделёнными тонкими линиями; строка светлеет на
  ховере.
- На мобильном стек и факты идут в одну колонку, шаги — номер и название в
  строке, текст под ними.

## Блоки и покраска

Фон блоков чередуется чёрный / белый, а не сами блоки: обложки, тексты, сетка
и содержимое остаются на месте. На инвертированном фоне текст переключается на
контрастный — это единственное, что меняется вместе с фоном.

- в работах чередование дают сами обложки: тьма / свет / тьма / свет / тьма / свет;
- «О себе» — белый блок, «Как я работаю» — чёрный;
- при входе в вьюпорт фон заливается как в хедере: три размытые кляксы
  целевого цвета сливаются goo-фильтром, затем проходит плотная волна. Копия
  проявляется вместе с заливкой. На `prefers-reduced-motion` — сразу финал.

## Дизайн-система

`design/design-system.json` — источник истины. Там:

- цвета и их роли;
- 8 ролевых пар «размер / интерлиньяж / трекинг» и шаги на 1100 / 640;
- 8-точечная шкала, радиусы, ширины колонки и сетки;
- motion: лоадер, вход героя, rise, один хедер, мобильная шторка, rows,
  Буп (исчезновение/появление, DevTools), контактная печать, свет за блоком,
  CTA-стекло, иконки, EyeTracker;
- компоненты (CTA, tray, case tile, фиксированный хедер, печать, spotlight,
  footer glyphs);
- иконки: сетка 24, штрих 1.7, round caps;
- персонаж, его пропсы, фазы гида и маппинг токенов;
- правила `doNot` и доступность.

Меняете токен — меняете `tokens.css` и JSON вместе. Кит читает JSON напрямую,
поэтому расхождение сразу видно.

## EyeTracker

Компонент Бенчо, MIT: https://bencho.dev/licence. Исходник сохранён с
комментариями; переименован экспорт `Watcher` → `EyeTracker`, реплики
переведены на русский, добавлен проп `say` для реплик гида.

Токены Бенчо не заведены новыми глобалами, а смаплены:

| Bencho | здесь |
| --- | --- |
| `--fill-slab` | `--white` |
| `--fill-on` | `--ink` |
| `--font-ui` | `--sans` |
| `--bg` | `--bg` |
| `--card` | `--surface` |
| `--ink` | `--ink` |

Где живёт:

- хедер, 25px, `Circle`, `idle` — логотип, клик меняет форму;
- Буп, 108px в hero и 72px в доке, `Cube`, следит за курсором; лица через
  брови (`mood`: normal / kind / angry / curious), сон через `sleeping`;
- лоадер, 120px, `idle`, морфит формы во время счёта;
- кит — песочница с переключателем форм.

Клик по шару открывает реплику. Это заготовка под будущее взаимодействие:
сейчас пул фраз и подсказки по блокам, дальше сюда можно повесить сценарий с
контактом.

## Контент

Данные в `src/data/site.ts`: кейсы ведут на реальные адреса (CRM, BigFoodMarket,
приглашения, Holly), стек и факты — из резюме. Метрик и логотипов клиентов,
которых нет, здесь нет.

Перед публикацией стоит проверить:

- актуальность ссылок и формулировок;
- нужен ли блок с резюме (PDF в проект не добавлен);
- нужна ли английская версия. Сейчас язык один — русский.

## Проверено

- `npm run build` — TypeScript + Vite, без ошибок.
- Playwright, 1440 / 900 / 390: нет горизонтального скролла, нет ошибок в
  консоли, один `h1`, все `[data-rise]` доезжают до `lit`.
- Хедер: `position: fixed`, всегда виден, Gooey Nav переключает активный пункт,
  мобильная шторка открывается на весь экран, пилюля остаётся сверху.
- Буп: исчезает/появляется в правой поляне, пузырь с хвостиком у шара,
  приветствие при входе, реплики и шутки по наведению, возврат после «ухода»
  в правильную точку; DevTools краснит, сон с жирными z z z.
- «Автобус 1»: 12 ссылок на сайты холдинга, 16 кадров в карусели, тексты про
  двенадцать сайтов.
- Блоки: фон чередуется тьма/свет, заливается goo-кляксами на скролле;
  содержимое и обложки не меняются.
- Работы: девять 16:9-карточек в сетке 3/2/1, ховер поднимает название,
  фильтры-чипы пересобирают сетку, пузырь Бупа не задевает карточки
  (на 1440 — 9px запаса).
- Карточка проекта: диалог открывается/закрывается, Escape, клик по фону,
  карусель листается стрелками, миниатюрами и клавиатурой, скролл без полосы,
  шесть фраз Бупа на проект.
- Мобильное меню: `aria-expanded`, Escape, `inert` на секциях под шторкой.
- `prefers-reduced-motion`: лоадер без полёта, rows без движения, печать
  стоит, Буп переключается без промежуточного пути, секции видны сразу.
- Лица: обычное / любопытное (hover, одна бровь) / доброе (poke) / злое
  (DevTools); меняются только брови, глаза стоят. Симуляция `outerWidth`
  даёт красное тело, нахмуренные брови, красный пузырь и реплику.
- Сон: 30 секунд простоя → глаза закрыты, `z z z`, движение будит.
- Злость: 4 быстрых тыка → колкость, улёт за экран, 10 секунд отсутствия,
  возврат с шуткой.
- Hover: поднимается одна правая бровь, глаза не двигаются.
- EyeTracker: клик выдаёт реплику; idle-версия в хедере не слушает указатель.
- Кит `/#kit` открывается и рендерит JSON.
